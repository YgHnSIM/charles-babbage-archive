# 0002. Astro + Tailwind CSS 기술 스택 및 심층 사료 해제 전략

웹페이지 구현 기술로 Astro와 Tailwind CSS를 채택하고, 19세기 1차 사료(빅토리아조 영문)를 단순 링크 제공에 그치지 않고 '원문 발췌 + 정밀 한글 번역 + 현대 컴퓨터 과학적 해설/코드 대조'의 3단계 가공을 거쳐 웹에 제공하기로 결정했다.

## 결정 이유
- Astro의 정적 콘텐츠 컬렉션(Content Collections) 및 초경량 HTML 렌더링 성능이 사료 아카이브에 최적화됨.
- 난해한 19세기 문헌의 핵심 개념(Mill, Store, Operation Cards, Bernoulli 수 계산표)을 현대 컴퓨터 공학 개념(ALU, RAM, 명령어 셋, 의사코드)과 1:1 대응 해설함으로써 독창적인 학술·교육적 가치를 확보함.
